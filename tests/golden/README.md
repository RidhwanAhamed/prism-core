# Golden traces

Replayable fixtures for the Task 2 parity test: replaying a trace's input records through
the C++ PCE must reproduce its recorded PSV trajectory within **1e-6 per dimension per
tick**. Format and replay procedure: `docs/fixture-capture.md` in the probe repo
(`prism-engine-probe`), reference replayer `src/pce/replay.ts` there.

## Files

**Replayable fixtures (`fixture-*.jsonl`)** — input events + tick instants + PSV
trajectory; every one verified to replay bit-exact through the probe's TS engine before
landing here:

- `fixture-scripted-deep-work-morning.jsonl` — 20 min focused; scatter patch, coffee-break
  idle, high-priority deadline ~29h out.
- `fixture-scripted-scattered-crunch-afternoon.jsonl` — 15 min heavy app switching in the
  post-lunch circadian dip; deadline 2h out; urgent task added mid-session.
- `fixture-scripted-wind-down-night.jsonl` — 12 min late evening; long away stretches,
  2-minute capture blackout, only a far low-priority deadline.
- `fixture-scripted-cold-sparse.jsonl` — 8 min; empty task list (deadline confidence 0),
  early blackout, capture/engine timer ticks colliding on the same instants.
- `fixture-live-smoke-2026-07-13.jsonl` — short real session through the actual Electron
  pipeline (wiring proof).

**Provenance note:** the scripted fixtures are generated by the probe's *validated* TS
engine (`test/fixture-generate.test.ts` in the probe repo) and deliberately exercise the
heuristic's branches. They prove **implementation parity** — the C++ port reproduces the
math. Real multi-minute dogfood captures (`PRISM_CAPTURE=1 npm run dev` in the probe)
additionally anchor the **validated feel** and should be added here before Task 8's
parity dogfood; the parity test picks up every `fixture-*.jsonl` automatically.

**Historical (`session-*.jsonl`)** — PSV-only dogfood logs from 2026-07-12, captured
before the input half existed. Not replayable; kept for reference. The parity test
ignores them.
